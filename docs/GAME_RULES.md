# Game Rules

## Game Modes
- Stack Duel: play the top card.
- Open-Hand Duel: choose an available card.

## Attributes
Strength, speed, agility, intelligence,
durability, energy. Ratings use a global 0-100 scale.

## Categories
Hosts can select genres, individual universes,
multiple universes, or all eligible cards.

## Status
Draft. Rules must be finalized before implementation.
